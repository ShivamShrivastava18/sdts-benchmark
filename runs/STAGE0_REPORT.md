## Gate

**Outcome: green.**

Rule, fixed before the pilot ran: green if the best baseline beats every deep model in every cell at n <= 1000; inverted if a deep model wins every such cell; ambiguous if the direction is mixed across cells with overlapping error bars. The outcome is reported, not chosen.

Strength: in 3 of 3 cells at n <= 1000 the winning margin exceeds the pair std; in 2 the +-1 std error bars overlap. The stricter all-methods pooled std is reported above as a sensitivity check and would call 0 of 3 cells decided.
